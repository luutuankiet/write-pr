# v0.2.4 — Trait 3 inversion + render-time lint

Fixes a rule bug where Trait 3 instructed agents to wrap `## Heading` *inside* `<summary>`, which silently mis-renders on GitHub (heading becomes the click-target, disappears when collapsed, drops out of the anchor-link graph). Trait 3 now keeps `## Heading` visible at the section level and wraps only the body in `<details><summary>Click to expand details</summary>`.

`src/render.ts` hard-errors on the antipattern (scans rendered `<summary>...</summary>` for `#{1,6}` heading lines) so future regressions fail at render, not silently on the PR view. New gotcha section in `rules/template-gotchas.md` + cross-ref refresh in `rules/callout-gotcha.md`. 2 new vitest cases gate the lint (67/67 green).

Install: `npx -y @luutuankiet/write-pr@latest install-skill` picks up the updated rule docs.
