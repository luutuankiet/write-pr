# v0.2.2 — block-level collapse heuristic

Docs / skill-content patch — no code change, no breaking change.

NEW Trait 3a in `rules/good-pr-traits.md`: block-level corollary to Trait 3's section-boundary wrap. Cognitive ceiling, not browser-perf — GitHub renders 500-row tables fine, but blocks that outscroll their own heading make reviewers lose orientation. Default thresholds: `md_table` / `delta_table` >10 rows, `json_pretty` >15 lines, `code_expand` >25 lines → compose with `| fold('<descriptive-summary>')`. Override permitted when the block IS the at-a-glance comparison; nesting forbidden when the enclosing `##` section is already `<details>`-wrapped.

Closes the under-folding gap: prior rules covered when to wrap whole sections (Trait 3) and how to compose folds (`fold` filter docs), but left agents guessing on individual-block size triggers — modal failure was dumping 30+ row tables inline because the reference PR anchored an inline-everything bias.

`placeholder-vocab.md` `md_table` section gets a one-line pointer to Trait 3a so agents catch the heuristic mid-template-write (not just on the read-first pass).

Install: `npx -y @luutuankiet/write-pr@latest install-skill` picks up the updated rule docs.
