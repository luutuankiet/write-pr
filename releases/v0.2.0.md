# v0.2.0 — generic filter set

Dropped `mermaid` filter (Mermaid sources rarely justify a `.mmd` evidence file — author inline instead) and `ci_summary` filter (overfit to dbt `run_results.json` — agents should pre-shape data + use `md_table`).

Added `delta_table` (two arrays → before/after table with computed Δ; numeric / string / missing all handled) and `fold` (compose-anywhere `<details>` wrap; replaces the coupled `json_pretty(fold=true)` flag).

Snippet swap: `ci_failure_section.j2` → `delta_table_perf.j2`. `mermaid_flowchart.j2` rewritten as inline-skeleton (no filter dep). Bundled minimal example demonstrates all 6 filters + inline mermaid.

**Breaking:** templates calling `| mermaid` or `| ci_summary` will fail to render. Migration: inline mermaid blocks; reshape CI JSON to `[{metric, value}]` rows and use `| md_table` or `| delta_table`.
